# ITI Social App

A modern social media application built with Flutter as part of the ITI training.

## Features

* User registration and login
* Forgot password
* Home feed
* Stories
* User profiles
* Profile information and tags
* Chat functionality
* Firebase authentication
* Clean and responsive user interface

## Technologies

* Flutter
* Dart
* Firebase
* Firebase Authentication
* Flutter Bloc / Cubit

## Project Structure

The project follows a clean and organized structure with separate screens, widgets, models, and authentication logic.

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run the application using `flutter run`.
